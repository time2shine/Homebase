## 5. Tagging Instructions (Awaiting Approval)

Once approved by the repository owner, the release will be committed and tagged using the following standard commands:

### Step 1: Stage and Commit Release Metadata
```powershell
git add package.json manifests/manifest.chrome.json manifests/manifest.firefox.json src/CHANGELOG.md docs/releases/
git commit -m "feat(release): prepare v0.18.0"
```

### Step 2: Push Release Commit to Development
```powershell
git push origin development
```

### Step 3: Create Annotated Release Tag
```powershell
git tag -a v0.18.0 -m "Homebase v0.18.0 — Monolith Deconstruction & Core Startup Architecture"
```

### Step 4: Verify Local Tag
```powershell
git tag -v v0.18.0
# or
git show v0.18.0 --stat
```

### Step 5: Push Tag to Remote
```powershell
git push origin v0.18.0
```

### Step 6: Verify Remote Tag
```powershell
git ls-remote --tags origin "v0.18.0*"
```

## 6. Rollback Instructions

In the event of an unexpected validation issue or rollback requirement:

### Scenario A: Prior to Committing (Current State)
To revert the version metadata bump in working tree:
```powershell
git checkout -- package.json manifests/manifest.chrome.json manifests/manifest.firefox.json src/CHANGELOG.md
git clean -fd docs/releases/
```

### Scenario B: After Local Commit, Before Push
To undo the release preparation commit while preserving working tree changes:
```powershell
git reset --soft HEAD~1
```
Or to discard completely:
```powershell
git reset --hard HEAD~1
```

### Scenario C: After Pushing Commit, Before Tagging
If an issue is found after pushing the commit to `origin/development`:
1. Create a revert commit:
   ```powershell
   git revert HEAD -m "revert(release): roll back v0.18.0 release preparation"
   git push origin development
   ```

### Scenario D: After Pushing Tag to Remote
If a remote tag must be retracted:
1. Delete local tag:
   ```powershell
   git tag -d v0.18.0
   ```
2. Delete remote tag:
   ```powershell
   git push --delete origin v0.18.0
   ```
3. Revert release commit on `development` if necessary.
