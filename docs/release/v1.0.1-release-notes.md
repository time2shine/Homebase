## 1. Release Executive Summary

**Homebase v1.0.1** is a targeted patch release that resolves transactional persistence and live preview defects in the Settings modal subsystem.

This release guarantees strict transactional compliance across every settings control in the dashboard:
1. **Atomic Settings Commit**: Settings changes are staged in memory and committed to persistent storage (`browser.storage.local` / `HomebaseStorage`) only when the user explicitly clicks the **Save** button.
2. **Reversible Live Previews**: Real-time visual previews (widget toggles, time format, tips card, wallpaper mode, and quality) remain responsive and interactive while remaining 100% reversible.
3. **Idempotent Rollback on Dismissal**: Clicking either the **Cancel** button or the modal header **Close (X)** button restores the initial settings snapshot and clears all active live previews.
4. **Elimination of Eager Storage Writes**: Removed all premature `localStorage`, `HomebaseStorage`, and widget preference writes triggered during control `change`, `click`, or `input` events.

---

## 2. Issues Resolved

### 2.1 Settings Modal Transactional Compliance
- **Premature Persistence**: Resolved an issue where toggling controls (such as "Show Homebase Tips" or widget visibility) immediately modified storage before the user decided whether to save or cancel.
- **Cancel / Close Parity**: Guaranteed that clicking the header Close (X) button executes the exact same rollback and cleanup sequence as clicking Cancel.
- **Tip Card Preview State**: Added `setHomebaseTipsPreviewOverride` to `HomebaseTipsUI`, ensuring discarded preview toggles properly restore the saved tip card visibility state.
- **Widget Drag Reorder Persistence**: Enhanced `scrapeFormValues()` to inspect the live physical ordering of `.widget-setting-row` elements in `#widget-sub-settings`, ensuring drag-and-drop order changes commit reliably on Save and revert cleanly on Cancel/Close.
- **Wallpaper Quality & Gallery Controls**: Removed eager storage setters from gallery interactions; quality selection is now staged and saved atomically.
