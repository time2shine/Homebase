## 1. Release Executive Summary

**Homebase v1.0.3** is a comprehensive stability and lifecycle release that hardens background-tab wallpaper behavior, restores clean crossfade state across tab visibility changes, refines Performance Mode and appearance preference preservation, resolves Settings dialog layout and scrolling constraints, aligns dashboard tips with browser capabilities, and establishes multi-browser packaging for Chrome, Firefox, and Microsoft Edge.

Key updates in this release:
1. **Wallpaper Tab Visibility Lifecycle**: Active live video wallpapers automatically pause when the tab becomes hidden, conserving CPU, memory, and battery resources. Returning to visibility cleanly resumes playback for eligible live wallpapers while keeping static wallpapers static and respecting Performance Mode and Battery Saver restrictions.
2. **Interrupted Crossfade Tracking & Recovery**: Introduced explicit crossfade transition tracking (`activeCrossfadeTransition`), transition identity binding, and idempotent completion. If tab visibility changes while a crossfade timer or frame callback is pending, returning to the tab safely resolves the interrupted transition to the target video without stuck dual-active videos, timer leaks, or listener duplication.
3. **Background Video Preloading**: Shifted background-tab video loading from browser-suspended `requestAnimationFrame` ticks to timer-based preloading, allowing video metadata to load cleanly while the tab is hidden without initiating playback.
4. **Performance Mode & Appearance Preservation**: Refined appearance overrides so Transparent Background and Custom Background color/opacity preferences are preserved across mode toggles. Background blur is cleanly disabled in Performance Mode without distorting text contrast or forcing gray backgrounds.
5. **Transactional Settings Persistence**: Serialized settings storage writes through sequential queuing (`_perfWriteQueue`, `_perfWriteTicket`), preventing out-of-order writes from corrupting or overwriting restored state when Cancel or Close is clicked. Dual-synchronized fast localStorage mirror keys (`fast-performance-mode` and `fast-perf-mode`).
6. **Wallpaper Type Guidance**: Added accessible inline notice and "Turn off Performance Mode" action button in both Settings and Wallpaper Gallery, preventing accidental switching from Static to Live Video while Performance Mode is enabled while preserving existing selections.
7. **Settings Dialog Layout & Scrolling**: Fixed toggle switch compression by enforcing non-shrinking flex bounds (`flex: 0 0 46px`) across settings controls, allowing multiline descriptions to wrap cleanly. Enforced dialog height constraints (`min-height: min(520px, calc(100vh - 40px)); max-height: calc(100vh - 40px)`), scrollable navigation with `min-height: 0; overflow-y: auto;`, and a fixed footer ensuring Save and Cancel buttons remain visible.
8. **Modal Animation Hardening**: Filtered bubbled child animation events, cleaned up entrance listeners on close and before reopen, and scoped `.modal-settled:not(.closing)` so closing shrink animations always run without replaying entrance animations on mode toggle.
9. **Perf Debug Overlay Clearance**: Controlled overlay horizontal positioning and dock clearance via declarative CSS custom properties (`--dock-width`, `--dock-gap`), collapsing cleanly on collapsed docks without conflicting inline styles or `!important`.
10. **Browser-Specific Tips**: Filtered dashboard tips dynamically by target platform (`HomebaseTipsCapabilities`), ensuring Chrome, Edge, and Firefox users only receive guidance relevant to their browser's capabilities and shortcuts.
11. **Browser Search Separation**: Chrome builds pass searches directly to Chrome's default search provider without an engine picker, while Edge and Firefox retain user-selectable search engine options (`google`, `bing`, `duckduckgo`, etc.). Firefox-only features (`contextualIdentities`, containers) remain strictly Firefox-only.

## 2. Issues Resolved

### 2.1 Background Tab Video Playback & Interrupted Crossfades
- **Issue**: Previously, background tabs could continue decoding and playing live wallpaper videos or attempt to trigger crossfade animations while hidden, leading to CPU usage on hidden tabs and broken, dual-active video states if a crossfade completion timer was interrupted.
- **Resolution**:
  - `handleWallpaperVisibilityChange()` pauses all active videos immediately upon `document.hidden`.
  - Extracted canonical `resumeWallpaperPlaybackIfEligible()` in `HomebaseWallpaperController` to evaluate mode, battery preference, and current selection before resuming.
  - Bound crossfade transitions to an explicit transition object with identity validation (`activeCrossfadeTransition === transition`) and idempotent completion (`finishCrossfade()`).
  - Stale async callbacks and delayed frame callbacks from interrupted transitions are safely discarded without mutating subsequent transitions.

### 2.2 Performance Mode Appearance Preservation & Persistence
- **Issue**: Enabling Performance Mode previously caused bookmark background styling to revert or display gray boxes, while rapid settings toggles could race storage writes, overwriting restored state on Cancel.
- **Resolution**:
  - Scoped Performance Mode CSS cascade overrides to preserve user-selected Transparent Background (`background: transparent`) and Custom Background opacity/color preferences while disabling costly background blur.
  - Implemented queue-based write serialization (`_perfWriteQueue`) and write ticket tracking (`_perfWriteTicket`) in `performance-controller.js` and `settings-panel-controller.js`.
  - Added "Turn off Performance Mode" action button in Wallpaper Gallery and Settings, providing clear guidance on why Live Video cannot be activated while Performance Mode is enabled.

### 2.3 Settings Dialog Layout & Animation Replay
- **Issue**: Multi-line descriptions compressed switch toggles into narrow ellipses; long Settings content overflowed the dialog and pushed Save/Cancel buttons out of view; opening Settings in Performance Mode replayed entrance animations on mode toggle.
- **Resolution**:
  - Enforced `flex: 0 0 46px; flex-shrink: 0;` on `.app-switch` and all `.app-setting-row` controls.
  - Established structured grid constraints (`grid-template-rows: minmax(0, 1fr)`) and scrollable navigation (`overflow-y: auto; min-height: 0;`) on `.app-settings-nav`.
  - Pinned `.app-settings-footer` with `flex-shrink: 0;` to guarantee persistent Save/Cancel visibility.
  - Filtered bubbled child animation events and scoped `.modal-settled:not(.closing)` to avoid replaying opening animations when toggling switches.

### 2.4 Browser-Target Guidance & Capabilities
- **Issue**: Users on Chromium-based browsers received tips mentioning Firefox Containers, while Firefox users could see irrelevant Chromium shortcuts.
- **Resolution**:
  - Introduced `src/newtab/tips/tips-capabilities.js` (`HomebaseTipsCapabilities`) to filter tips based on runtime build target (`chrome`, `firefox`, `edge`).
