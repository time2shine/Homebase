## 1. Release Executive Summary

**Homebase v1.0.5** is a maintenance and reliability release focusing on context-menu visual stability, persistent offline favicon caching, and privacy-preserving favicon fallback handling for local and private network addresses.

Key updates in this release:
1. **Context Menu Instant Repositioning**: Context menus across empty grid space, bookmark tiles, subfolder tiles, and folder tabs now reposition immediately between right-click locations without sliding or animating across the dashboard.
2. **Offline Favicon Persistence**: Favicon cache keys now use normalized HTTPS-shaped local identifiers (`https://favicons.homebase.local/`), eliminating browser `CacheStorage` scheme rejections (`TypeError: Request scheme 'chrome-extension' is unsupported`) and ensuring previously loaded favicons persist across offline reloads and restarts.
3. **Local & Private Address Favicon Fallback & Privacy**: Bookmarks and search results pointing to private or local addresses (private IPv4, loopback, link-local, CGNAT, `localhost`, `.local` mDNS, single-label intranet hosts, and IPv6 private addresses) display stable letter/generic fallbacks without leaking addresses to external favicon providers or repeatedly loading stale cached placeholders.
4. **Exact IPv6 Classification Boundaries**: Validated IPv6 ULA (`0xfc00`–`0xfdff`) and link-local unicast (`0xfe80`–`0xfebf`) ranges using exact numeric boundary parsing on the first 16-bit group, preventing short-group false matches (`fc::1`, `fd::1`, `fe8::1`) and excluding deprecated site-local addresses (`fec0::1`).

## 2. Issues Resolved

### 2.1 Context Menu Instant Repositioning
- **Issue**: Right-clicking consecutive targets across the dashboard caused the context menu to visibly slide or glide between coordinates due to inherited CSS transitions (`all 0.3s ease` in dynamic glass styling).
- **Resolution**:
  - Enforced `transition: none !important;` on `.context-menu` and `.context-menu.glass-box` in `src/new-tab.css` and inside dynamic glass styling in `src/newtab/settings/visual-effects-runtime.js`.
  - In `src/newtab/core/context-menu-controller.js`, updated `reposition()` to assign `menuEl.style.left` and `menuEl.style.top` before restoring visibility.

### 2.2 Offline Favicon Persistence
- **Issue**: Cached favicons failed to display offline after reloading or restarting the browser, falling back to letter placeholders even though other cached content remained available.
- **Resolution**:
  - Root Cause: Relative cache keys (e.g. `/favicons/domain@48`) resolved against the extension document origin (`chrome-extension://...`). Browser `CacheStorage` rejects non-HTTP(S) request schemes and throws a `TypeError`.
  - In `src/newtab/core/favicon-pipeline.js`, introduced `FAVICON_CACHE_KEY_PREFIX = 'https://favicons.homebase.local/'` and `normalizeCacheKey()`, ensuring all `CacheStorage` operations use valid HTTPS-shaped local identifiers.
  - Refined `loadObjectUrlIntoImage` to verify `if (img.complete && img.naturalWidth > 0)` before finalizing, allowing newly assigned images to decode asynchronously.

### 2.3 Local & Private Address Favicon Fallback & Privacy
- **Issue**: Bookmarks with local/private URLs (such as `http://192.168.0.160:1111/`) made external network requests to third-party favicon providers and loaded generic or stale cached placeholders.
- **Resolution**:
  - Implemented `isLocalOrPrivateHost()` and `isPrivateOrLocalIpv4()` classifying private IPv4 ranges (RFC 1918 10/8, 172.16/12, 192.168/16, loopback 127/8, link-local 169.254/16, CGNAT 100.64/10, test-nets, multicast/broadcast), `localhost` and its subdomains, `.local` mDNS, and single-label intranet hostnames.
  - Local/private URLs reject external candidate generation and immediately trigger `onFailed()`, bypassing `faviconResolvedCache`, `CacheStorage`, and network fetching.
  - In `src/newtab/bookmarks/bookmark-grid-controller.js`, recycled tile images are cleared and immediately assigned `showFallbackNow('local-private-target')`.
  - In `src/newtab/search/search-results-renderer.js`, `hydrateFavicons` hides favicon images for local/private bookmark URLs. Custom icons selected explicitly by the user remain fully supported.

### 2.4 Exact IPv6 Classification Boundaries
- **Issue**: Regex-based IPv6 prefix matching allowed shorter hexadecimal groups (e.g., `fc::1`, `fd::1`, `fe8::1`) to match intended 16-bit ranges.
- **Resolution**:
  - Required exact numeric parsing of the first 16-bit group: ULA (`0xfc00`–`0xfdff`) and link-local unicast (`0xfe80`–`0xfebf`).
  - Correctly excludes short prefixes (`fc::1`, `fd::1`, `fe8::1`) and deprecated site-local addresses (`fec0::1`). Supports IPv4-mapped IPv6 in both dotted and hex normalized formats.
