## 1. Release Executive Summary

**Homebase v1.0.2** is a targeted patch release that resolves bookmark tile inline-rename layout shifting, refines the bookmark background configuration with mutually exclusive Transparent vs Custom toggles and nested grouping, corrects the opacity hint range, and fixes a schema validator fallback defect that previously prevented unconfigured profiles from cleanly defaulting to Transparent mode.

Key updates in this release:
1. **Bookmark Rename Layout Stability**: Prevents flex container expansion and visual displacement when renaming bookmark tiles directly on the dashboard grid.
2. **Mutually Exclusive Background Modes**: Transparent mode and Custom Background mode are now coordinated as mutually exclusive states with reliable state synchronization.
3. **Nested Sub-Settings Organization**: Custom Background controls (color picker, opacity, and blur sliders) are visually grouped in a nested container that appears only when Custom Background is enabled, preserving clean aesthetics.
4. **Transparent Default Schema Fix**: Aligned `appBookmarkTextBg` schema validation definition and fallback (`default: false`, `fallback: false`) with `defaultSettingsState`, ensuring profiles without saved background preferences default cleanly to Transparent mode upon startup and reload.
5. **Accurate Settings Guidance**: Corrected the Background Opacity hint text to accurately reflect the 10% to 100% slider range.
6. **Folder Edit Context Resolution**: Hardened `HomebaseContextMenuController` and `bookmark-editor-adapter.js` to resolve bookmark folders cleanly whether referenced by string ID or node object.

## 2. Issues Resolved

### 2.1 Bookmark Inline-Rename Layout Shift
- **Fixed Tile Expansion**: Removed height overrides and flex re-alignment on `.bookmark-item.is-renaming` that caused grid items to displace neighboring tiles during inline rename.
- **Elevation without Shift**: Positioned the inline rename input cleanly over the tile title area with elevated `z-index: 5` and defined max-width bounds.

### 2.2 Bookmark Background Settings & Visual Nesting
- **Mutually Exclusive Toggles**: Toggling Transparent Background automatically turns Custom Background off (and vice versa) across UI events and settings state.
- **Nested Control Hierarchy**: Opacity, blur, and text background color controls are now neatly contained within `#app-bookmark-custom-bg-sub-settings` with subtle left-accent border styling, collapsing completely when Transparent mode is active.
- **Slider Preservation**: Switching between Transparent and Custom modes retains previously chosen color, opacity, and blur values in memory and persistent storage.

### 2.3 Transparent Mode Fallback Defect
- **Root Cause**: `SCHEMA_DEFINITIONS.appBookmarkTextBg` in `schema-validator.js` previously specified `default: true` with a fallback to `true` whenever the key was missing or undefined.
- **Fix**: Updated `appBookmarkTextBg` in `src/newtab/core/schema-validator.js` to `default: false` and `fallback: false`. Profiles with removed or unconfigured keys now cleanly initialize to Transparent mode without synthetic overrides.

### 2.4 Folder Context Menu and Adapter Robustness
- **Context Menu Node Resolution**: Added `resolveBookmarkNode()` in `context-menu-controller.js` to inspect grid folder children, synchronous bookmark tree caches, and DOM element fallbacks.
- **Adapter Flexibility**: Updated `showEditFolderModal(folderNodeOrId)` in `bookmark-editor-adapter.js` and `bookmark-editor.js` to accept either folder IDs or folder node objects interchangeably.
